## 5. Confirmed claims (with evidence)
- All 15 `test_slack` tests pass on the draft (`... ok` ×15 in the §1 run).
- Live `check` against the real workspace: `auth ok`, `bot_is_member=True`, `history ok`, exit 0.
- No token, channel-id or home-path literal in any draft file. Scrub hits are confined to the coordination docs (§1).
- `plugin validate --strict` passes for marketplace, manifest, skills and agents.
- History `oldest` handling matches real Slack (exclusive). The extra `ts > floor` filter makes dedupe robust either way, and the control mutant removing it is killed.
- Float `ts` handling is safe for current epochs: microsecond steps (1e-6) exceed double spacing near 1.7e9 (~2.4e-7). The worker found 0/1e6 round-trip mismatches below 8.6e9.
- The misnamed-`.env` hint prints file names only, never contents (`slack_bridge.py:47`).
